# Folheto Digital – Ofertas de Novembro (Black 2026)

Página interna do time comercial com as campanhas de novembro de Escola Trabalhista, Dedicação Delta, AprovaçãoPGE e Aprovação Tribunais.

- Site estático: tudo está no `index.html` (sem build).
- A aba **Demais cursos** fica travada até **12/11/2026 às 00h (horário de Brasília)** e libera sozinha na data.
  A data fica na constante `UNLOCK` dentro do `index.html`.
- A página não é indexada por buscadores (`noindex`) e tem cabeçalhos de segurança definidos em `vercel.json`.
- Para atualizar: edite o `index.html` e faça push na branch `main`. A Vercel publica automaticamente.
